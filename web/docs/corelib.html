CoreLib

Pixelscript comes with an optional core library modules. They sit behind the pxs module.

To use the core library you must run pxs_core_initall(). Or you can initialize specific modules.

Specific Modules

There are specific modules in pixelscript that can be added or not.

Module Enum Value
pxs.mem pxs_ModuleFlag::pxs_MEM 2
pxs.os pxs_ModuleFlag::pxs_OS 4
pxs pxs_ModuleFlag::pxs_PXS 8
pxs.fs pxs_ModuleFlag::pxs_FS 16
pxs.shell pxs_ModuleFlag::pxs_SHELL 32

pxs.cross
RuntimeObjectType

Determines what the #`RuntimeObject` can and can not do.

Runtime = [_call, _exec, _eval, _get, _set].

Function = [_call]

Object = [_call, _get, _set]

Runtime = 0

Function = 1

Object = 2

RuntimeObject

A value from another runtime. Each `RuntimeObject` operates differently. See #`RuntimeObjectType` for more details.

RuntimeObject
_call

Paramaters are:

  1. name: pxs_String|pxs_List Can be either the name or args if calling itself.)
  2. args: pxs_List? arguments of the function. Is only null when passing args as name.))

Returns: RuntimeObject|pxs_Va

Depending on the `type`, it will either call a function or call itself.

If `type` is Runtime, it will call a function.

If `type` is Function, it will call itself.

If `type` is Object, it will call a property of itself.

                
from pxs import print
from pxs.cross import access

lua = access(0)
lua._exec("function add(n1, n2) return n1 + n2 end")
add = lua._get('add')
print(add._call([1,2]))
_get

Paramaters are:

  1. name: pxs_String the name of the variable.))

Returns: RuntimeObject|pxs_Va The result of the get.

Get a variable/object/function.

If `type` is Runtime, it will get from global scope.

If `type` is Object, it will get a property of itself.

                
from pxs import print
from pxs.cross import access
js = access(2)
js._exec("""
    globalThis.Me = {
        name: "Jordan"
    };
""")

js_me = js._get('Me')
print(js_me._get('name'))
