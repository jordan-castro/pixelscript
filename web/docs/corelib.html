PXS Docs

CoreLib

Pixelscript comes with an optional core library modules. They sit behind the pxs module.

To use the core library you must run pxs_core_initall(). Or you can initialize specific modules.

Specific Modules

There are specific modules in pixelscript that can be added or not.

pxs.fs
ReadFile

How to read a file. Pass in `read_file`.

Text = 1

Bytes = 2

OpenType

How to open a file. Pass in `File`.

Read = 1 << 0

Write = 1 << 1

Append = 1 << 2

File

Access to a File.

Our pxs exposed File object

File

Paramaters are:

  1. path: pxs_String path to the file.)
  2. open_file: pxs_Int64 open file type. Defaults to READ.))

Returns: fs-File

Open or create a new #`fs-File`.

open_file is defaulted to Read if not passed.

f.write('test')
f.close() # remember to close your files.
