PXS Docs

Getting Started

Beginning with pixelscript is meant to be easy, readable, and fun!

After having experienced multiple different scripting runtimes, pxs (short for pixelscript) is a pretty pretty pretty easy way to embed a language inside your application. Or build one using it!

Installing

To install the library clone the github repository

Then run:

python3 scripts/build.py

This will build the libraries needed for working.

If you are using rust, then you can simply add the crate to your project.

cargo add pixelscript

The docs assume the C programming language.

Hello World

To do a hello world program, you will need:

  1. CoreLib enabled (at least pxs).
  2. Initializtion.

This is enabled by default when running the above python build.

            
            // include the pixelscript header.
            #include "pixelscript.h"

            int main() {
                // setup pxs
                pxs_initialize(); // all of the pixelscript api uses a `pxs` prefix.
                
                // setup corelib
                pxs_core_initall();

                // a simple script
                char* script = "from pxs import print\n"
                                "print('hello world')";
            
                // execute
                pxs_VarT result = pxs_exec(pxs_Python, script, "");

                // check for errors
                if (pxs_isexception(result)) {
                    char* err = pxs_getstring(result);
                    printf("%s\n", err);
                    pxs_freestr(err); // always free strings from pxs.
                }

                // free the result
                pxs_freevar(result);

                return 0;
            }

Yes it is that simple!
